===> C’est quoi Git ?

Git est un logiciel de gestion de versions décentralisé. C'est un logiciel libre créé par Linus Torvalds, auteur du noyau Linux, il permet de suivre les modifications apportées au code source, de collaborer efficacement et de gérer différentes versions d'un projet.

===> C’est quoi GitHub ?

GitHub est un service web d'hébergement et de gestion de développement de logiciels, utilisant le logiciel de gestion de versions Git. GitHub propose des comptes professionnels payants, ainsi que des comptes gratuits pour les projets de logiciels libres. le site offre de nombreuses fonctionnalités habituellement retrouvées sur les réseaux sociaux comme les flux, la possibilité de suivre des personnes ou des projets ainsi que des graphes de réseaux pour les dépôts

===> Quelle est la différence entre Git et GitHub ?

Git = outil local de gestion de versions ; 
GitHub = service en ligne pour héberger et collaborer sur des dépôts Git.

Git gère l’historique et les versions ; 
GitHub facilite le partage, la révision et la coordination d’équipe.

Git = ligne de commande (avec options GUI) ; 
GitHub = interface web conviviale.

Git seul pour projets locaux ; 
Git + GitHub pour travail collaboratif et open source.

===> À quoi servent commit, push et pull ?

Commit: Crée un instantané de vos modifications préparées. 
Push: Transfère les commits locaux vers le dépôt distant. 
Pull: Récupère les commits du dépôt distant et les fusionne dans votre branche locale.
